Lab 1: Starting a Git Repository

Create a local Git repository, initialize version control, and record the first commit.

Commands / workflow

git init
 git status
 git add .
 git commit -m "Initial commit"

Explanation

A local Git repository tracks changes to project files. The commands shown initialize the repository and create the first commit.

Note: Complete the Git operations in your own terminal and attach your actual repository evidence if required by your instructor.
